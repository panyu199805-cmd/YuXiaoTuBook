## 一、一键复现提示词（直接复制使用）

```
请为 Vue3 + TypeScript + Element Plus + Vue Router + Pinia 项目搭建一套后台管理布局（AdminLayout），要求完全实现以下左侧菜单栏风格与动态交互效果：

## 技术栈
- Vue 3 Composition API（script setup）
- Element Plus（el-menu、el-sub-menu、el-menu-item、el-popover、el-autocomplete、el-breadcrumb、el-tooltip）

## 整体布局结构
左右分栏全屏布局（height: 100vh）：
- 左侧 Sidebar：展开宽 248px，折叠宽 72px，白到浅蓝渐变背景，右边框 #e5e6eb
- 右侧 Main：顶栏 Topbar（60px）+ 多标签 TabBar + 内容区 Content（padding 18px，可滚动）
- 页面背景色 #f4f7fe，主色 #5d87ff

## 左侧 Logo 区
- 高度 68px，底部细边框
- 左侧 40×40 圆角方块 Logo（渐变 #5d87ff → #7c3aed，显示「宇」字，带阴影）
- 展开时右侧显示两行：「宇小兔每日读书」（15px 加粗）+「后台管理系统」（12px 灰色）
- 折叠时只保留 Logo 图标

## 菜单数据结构（一级 + 二级）
在 adminMenu.ts 中定义 AdminMenuGroup[]，每组包含：
- key（唯一标识，如 analytics）
- title（一级菜单名）
- icon（Element Plus 图标组件）
- scope（可选权限：all / super / finance）
- children[]：{ path, title, icon?, scope? }

共 7 个一级菜单（按顺序）：
1. 数据分析（5 个二级）
2. 书籍管理（4 个二级）
3. 内容管理（4 个二级）
4. 氛围配置（3 个二级）
5. 会员管理（4 个二级）
6. 订单管理（4 个二级）
7. 权限管理（4 个二级，仅 super 可见）

路由格式：/admin/{groupKey}/{pageKey}，如 /admin/analytics/overview
根据用户名过滤菜单（admin 可见全部，普通管理员隐藏 super 级菜单）

## 展开态侧栏菜单（collapsed = false）
使用 el-menu + el-sub-menu + el-menu-item，关键配置：
- :collapse-transition="false"（禁用折叠动画）
- 不使用 unique-opened（允许多个一级菜单同时展开）
- 用 openedMenus: string[] 手动管理 @open / @close
- 路由变化时自动 ensureMenuOpened，将当前页所属一级菜单加入 openedMenus
- 一级标题：margin 2px 10px，圆角 10px，字重 600，带图标
- 二级项：margin 2px 10px 2px 18px，圆角 8px，带图标，激活态渐变背景
- 激活二级项：linear-gradient(90deg, rgba(93,135,255,0.16), rgba(93,135,255,0.06))，主色文字加粗
- 已展开一级标题：浅蓝背景 rgba(93,135,255,0.1)，主色文字

### 悬停延迟展开二级菜单（核心交互）
- 鼠标移入 el-sub-menu 后延迟 320ms 才触发二级展开（降低误触灵敏度）
- 实现方式：@mouseenter 找到 .el-sub-menu，若未 is-opened，setTimeout 320ms 后模拟点击 .el-sub-menu__title
- @mouseleave 时 clearTimeout 取消待展开
- 仍保留点击箭头手动折叠/展开

### 防止二级菜单缩进抖动
在 admin-theme.css 中强制：
```css
.admin-side-menu .el-menu--inline {
  padding-left: 0 !important;
  transition: none !important;
}
```

## 折叠态侧栏菜单（collapsed = true）

- 每个一级菜单一个 44×44 圆角按钮，仅显示图标
- 当前路由所属一级高亮（active 态：浅蓝背景 + 主色 + 内描边）
- 悬停 280ms 后弹出飞层（placement: right-start，宽 248px，无箭头，offset 6）
- 飞层结构：
  - 头部：渐变背景条 + 一级图标（32×32 渐变方块）+ 一级标题（14px 加粗）

- 双击一级图标按钮：展开侧栏（collapsed=false）+ 将该一级菜单加入 openedMenus

## 六、关键代码实现要点（避免 AI 生成偏差）

### 6.1 悬停延迟展开（不要用 el-menu 默认 hover）

```typescript
const HOVER_OPEN_DELAY_MS = 320
let hoverOpenTimer: ReturnType<typeof setTimeout> | null = null

function openSubMenuOnHover(event: MouseEvent) {
  const subMenu = event.currentTarget as HTMLElement | null
  if (!subMenu?.classList.contains('el-sub-menu') || subMenu.classList.contains('is-opened')) return
  if (hoverOpenTimer) clearTimeout(hoverOpenTimer)
  hoverOpenTimer = setTimeout(() => {
    if (subMenu.classList.contains('is-opened')) return
    const title = subMenu.querySelector('.el-sub-menu__title') as HTMLElement | null
    title?.click()
    hoverOpenTimer = null
  }, HOVER_OPEN_DELAY_MS)
}

function cancelSubMenuHoverOpen() {
  if (!hoverOpenTimer) return
  clearTimeout(hoverOpenTimer)
  hoverOpenTimer = null
}
```

绑定到 `<el-sub-menu @mouseenter="openSubMenuOnHover" @mouseleave="cancelSubMenuHoverOpen">`。

### 6.2 折叠态不能用 el-menu--collapse

折叠态必须**切换为独立 DOM 结构**（图标按钮 + popover），而不是 Element Plus 的 `collapse` 模式，否则无法实现美观飞层和双击展开。

```vue
<el-menu v-if="!collapsed" ... />
<div v-else class="collapsed-nav">
  <el-popover v-for="group in menuGroups" trigger="hover" :show-after="280" ...>
    ...
  </el-popover>
</div>
```

### 6.3 模糊搜索算法

```typescript
export function fuzzyMatchMenuText(text: string, query: string) {
  const source = text.toLowerCase()
  const keyword = query.trim().toLowerCase()
  if (!keyword) return true
  if (source.includes(keyword)) return true
  let start = 0
  for (const char of keyword) {
    const index = source.indexOf(char, start)
    if (index === -1) return false
    start = index + 1
  }
  return true
}
```

### 6.4 路由联动

```typescript
watch(() => route.path, (path) => {
  ensureMenuOpened(path)   // 自动展开所属一级菜单
  tabsStore.addTab(route)  // 自动添加标签
}, { immediate: true })
```

### 6.5 防缩进抖动 CSS（必须写）

```css

  padding-left: 0 !important;
  transition: none !important;
}

## 七、常见问题与修正提示词

| 问题现象 | 修正提示词 |
|----------|-----------|
| 悬停一级菜单立刻展开，太灵敏 | 给 el-sub-menu 增加 320ms 延迟展开，mouseleave 时取消定时器 |
| 二级菜单展开时文字左右跳动 | 对 .el-menu--inline 设置 padding-left:0 且 transition:none |
| 折叠后只有窄条菜单，没有飞层 | 折叠态不要用 el-menu collapse，改用 el-popover 自定义飞层 |
| 只能展开一个一级菜单 | 移除 unique-opened，用 openedMenus 数组手动管理 |
| 搜索时侧栏菜单被过滤消失 | 搜索只用于 autocomplete 跳转，侧栏始终渲染完整 menuGroups |
| 右上角管理员名称被挤压换行 | topbar-right 设 flex-shrink:0，搜索框宽 200px，昵称 white-space:nowrap |
| 标签栏样式不统一 | 标签与「清空记录」按钮同排，统一 pill 圆角边框风格 |
| 折叠态无法回到展开态 | 顶栏加折叠按钮；支持双击一级图标 expandSidebarFromGroup |
